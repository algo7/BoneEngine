# Changelog

## 1.0.3

- Added Hexium release workflows.
- First release on Hexium. Earlier versions are only on [Thunderstore](https://thunderstore.io/c/valheim/p/Algo7/BoneEngine/versions/).

## 1.0.2

- Page: corrected the real-world drag formula in Engine Power (hull area under water, not frontal area).

## 1.0.1

- If the engine ever runs into an error (for example after a game update), it now switches itself off for the
  session and boats sail as vanilla, instead of retrying every moment. The count lines hide with it.
- The bone count no longer shows 0 on a boat whose storage hasn't finished loading.

## 1.0.0

- First release: bone fragments in a boat's storage run an engine that pushes both forward and in reverse and
  burns the bones while it pushes. The count shows on the steering panel and the rudder.
